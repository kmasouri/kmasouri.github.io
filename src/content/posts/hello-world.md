Welcome to the new site! If you landed here from a direct link, you skipped the
BIOS screen. Go back to the [desktop](/) in a fresh tab if you want the full
experience.

## Why build a static site?

I wanted a place to write that felt permanent and fully mine:

- **URLs were ugly** and I couldn't control them.
- **Pages were slow** to load and hard for search engines to read.
- **My writing lived in someone else's database**, not in plain files I own.

Now every post is a Markdown file in a git repo. GitHub builds it into plain
HTML, serves it for free, and I can open my archive in any text editor.

## Why does it look like Windows XP?

Because the first computer I really *messed around with* looked like this, and
a personal site should feel personal. Under the retro look it's a normal static
site: real links, real headings, and it works without JavaScript.
