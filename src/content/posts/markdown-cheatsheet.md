Copy this file to start a new post. The file name becomes the URL, so
`my-new-post.md` is published at `/posts/my-new-post/`.

## Headings

Use `##` for sections and `###` for subsections. The post title is already the
page's main heading, so skip `#`.

### A subsection

Like this.

## Text

You can write **bold**, *italic*, `inline code`, ~~strikethrough~~, and
[links](https://kmasouri.github.io/).

## Images

Put images in `src/assets/blog/` and link them with a relative path. Always add
alt text in the square brackets. It's what screen readers read aloud.
